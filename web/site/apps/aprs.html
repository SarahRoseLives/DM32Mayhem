What it does

The APRS transmit app: send a status, a message to another station, or your current position, keying and unkeying the radio itself.

Network builds add KISS and iGate paths to the APRS-IS.

How to use it

  1. Open TX → APRS.
  2. Set your Callsign and Frequency.
  3. Fill in a Status, or the Message to and Message rows.
  4. Select Send status, Send message or Send position now.

Screen fields

Callsign
Your station, with an SSID if you use one.
Frequency
The APRS channel.
State / Status
The status text to beacon.
Message to / Message
A directed APRS message.
Send status / message / position
Queue the transmission.

Position needs a GPS fix; the network paths need the KISS/iGate build.
