Packet BBS

A small connected-mode packet mailbox that runs in the radio.

What it does

A packet BBS on the radio's 1200-baud AFSK modem. It answers a caller, shows a banner, runs the usual connected-mode commands and keeps a mailbox in the data flash.

It is configured entirely on its own screen, and can start automatically at power-on.

How to use it

  1. Open TRX → BBS.
  2. Set Frequency, Bandwidth, Callsign and SSID, plus the BBS name and Sysop shown in the banner.
  3. Set TX delay and the CW ID interval if you want an identifier.
  4. Select Start BBS; the header shows Running with the callsign and frequency.

Screen fields

Start BBS
Start or stop the server.
Frequency / Bandwidth
The RF channel, 12.5 or 25 kHz.
Callsign / SSID
The BBS's own AX.25 address.
BBS name / Sysop
Shown in the banner.
TX delay
KISS TXDELAY in 10 ms units.
Start at power on
Run the BBS as soon as the radio boots.
CW ID
Morse identifier interval: off, 5, 10, 15 or 30 minutes.

The RF path is the APRS engine's; APRS beacons are off while the BBS runs.
