FM transceiver

A real FM transceiver with live PTT, repeater offset and CTCSS.

← All apps Flash your radio →

What it does

The one screen where the handheld behaves like a normal FM radio. Set the transmit and receive frequencies independently, pick a repeater offset, and give RX and TX their own CTCSS tone.

Hold PTT to talk and release to listen. The header turns red and shows TX while keyed, and the Signal row shows the live level.

How to use it

  1. Open TRX → FM.
  2. Set TX and RX; TX is the frequency the radio transmits on.
  3. Set Offset for a repeater, and CTCSS RX / CTCSS TX if the repeater uses a tone.
  4. Hold PTT to talk; release to listen.

Screen fields

TX
Transmit frequency.
RX
Receive frequency.
Offset
Off, up/down shift, or a split frequency.
CTCSS RX / TX
Per-direction tone.
Signal
Live receive level in dBm.

Manual PTT is only in this screen. Everywhere else the apps key the radio themselves.
