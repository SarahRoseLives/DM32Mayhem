MDC-1200

MDC-1200 ANI and PTT ID bursts.

← All apps Flash your radio →

What it does

Sends the MDC-1200 signalling burst that many commercial radios use for unit identification (ANI) and PTT ID.

How to use it

  1. Open TX → MDC.
  2. Set Frequency and the Opcode.
  3. Set the Unit ID and Source bytes.
  4. Select Transmit MDC.

Screen fields

Frequency
The channel to key.
Opcode / Argument
The MDC message type.
Unit ID hi / lo
The sending unit's number.
Source hi / lo
The source fields.
Transmit MDC
Send the burst.
