Transmit · TX → OOK

OOK

On-off keying for fixed-code remotes and 433.92 MHz devices.

← All apps Flash your radio →

What it does

Keys the carrier on and off to send fixed-code remote signals. Use a hex code for a known device, or a de Bruijn sequence to sweep every code of a given order.

How to use it

  1. Open TX → OOK.
  2. Set Frequency and Bit length.
  3. Pick Mode (De Bruijn or Hex) and Data (an order, or a code).
  4. Set Repeat and select Transmit OOK.

Screen fields

Frequency
The carrier, e.g. 433.920 MHz.
Bit length
Pulse width per bit in microseconds.
Mode
De Bruijn sweep or a hex code.
Data
The sequence order or the code.
Repeat
How many times to send it.

Timing is limited by the PA settling time — about 1 ms per bit.
