P25 control channel

A P25 Phase 1 control channel transmitter.

What it does

Builds and transmits a P25 Phase 1 control channel: the frame sync, BCH Network ID, TSBK, trellis coding, interleaving and outbound status symbols, rotating IDEN_UP, NET_STS, RFSS_STS and a group voice grant.

The modem sends it as continuous 4FSK.

How to use it

  1. Open TX → P25.
  2. Set Frequency, NAC and WACN.
  3. Set the System ID, RFSS, Site and Talkgroup, plus the Voice channel.
  4. Select Transmit P25 CC; abort from the app.
