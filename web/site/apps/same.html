SAME

NOAA/EAS SAME weather headers over AFSK.

← All apps Flash your radio →

What it does

Sends a SAME header — the 520.83-baud AFSK burst used by NOAA Weather Radio and the Emergency Alert System — on a weather frequency. The header is assembled from the originator, event, FIPS location and duration.

How to use it

  1. Open TX → SAME.
  2. Set Originator, Event, the FIPS state and county, and the Duration.
  3. Set the Frequency and Station ID; the header preview updates at the top.
  4. Select Transmit SAME.

Screen fields

Originator
WXR, EAS, CIV or PEP.
Event
The three-letter event code, e.g. RWT.
FIPS state / county
The location code.
Duration h / min
How long the alert runs.
Frequency / Station ID
The channel and sender ID.
Transmit SAME
Send the header.

Only transmit on frequencies you are licensed for; SAME is a real alerting signal.
